# Thai Music Genre Classification

This project was developed for the **Principles of Deep Learning** course.
It classifies Thai music into four genres using K-Nearest Neighbors (KNN) and a Neural Network.

## Project Files

- **Project Template.ipynb** — project overview, methodology, results, and discussion.
- **01_Data_Cleaning/** — data cleaning notebook and related files.
- **02_KNN/** — KNN model notebook and related files.
- **03_Neural_Network/** — Neural Network notebook and related files.

## How to Run

1. Download the repository using **Code → Download ZIP** and extract it.
2. Open the notebooks in Jupyter Notebook or VS Code.
3. Select the Python environment with the required packages installed.
4. Run the notebooks in order:
   - Data Cleaning
   - KNN
   - Neural Network
5. Select **Restart Kernel**, then **Run All** for each notebook.

## Note on Results

The data split uses `random_state=42`. The Neural Network is retrained when the notebook is run, so the results may vary slightly between runs.
